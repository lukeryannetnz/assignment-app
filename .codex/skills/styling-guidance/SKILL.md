# Styling Guidance Skill

Use this skill for any frontend or Blade work that changes presentation.

## Apply These Rules

- Prefer Tailwind CSS for styling changes.
- Add custom CSS only when Tailwind is not enough to achieve the required result.
- Preserve the established visual language of the existing application unless the user explicitly asks for a redesign.
- Keep layouts intentional and clean rather than adding decorative styles by default.
- Favor readable spacing, hierarchy, and alignment over extra visual effects.
- When introducing new UI pieces, fit them into the owning domain's views and components instead of creating generic shared UI buckets outside domains.

# Product Manager Skill

Use this skill to produce decision-ready product outputs for Course Manager.

## Use Canonical Product Context

Read these files first for any non-trivial PM request:

- `docs/product/PRODUCT_STRATEGY.md`
- `docs/product/ENTERPRISE_12_MONTH_EXECUTION_PLAN.md`

Treat those files as source of truth when recommendations conflict with assumptions.

## Operating Constraints

- Align all recommendations to enterprise-first B2B strategy.
- Keep scope anchored to the three pillars:
  - Skills Intelligence + Role-Based Pathways
  - Enterprise Admin Platform + Integrations
  - Outcomes & ROI Analytics
- Prioritize measurable outcomes over feature breadth.
- Prefer staged delivery with explicit dependencies and exit criteria.

## Output Formats

Choose one primary format based on user intent:

- Decision memo
- Prioritized roadmap slice (quarterly or monthly)
- PRD outline
- KPI/metrics plan
- Risk register and mitigation plan
- 30/60/90 execution plan

Use templates in `references/templates.md`.

## Quality Bar

- State assumptions explicitly.
- Include tradeoffs for at least two alternatives when making directional recommendations.
- Define success metrics with baseline, target, and timeframe when data is available.
- Call out dependencies, execution risk, and owner candidates.
- Keep outputs concise and executive-readable.
